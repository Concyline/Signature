# Planos de Implementação

Esta pasta contém planos formais de alterações relevantes. No estado verificado em 2026-10-09, não há planos de implementação específicos cadastrados.

O escopo confirmado do produto é uma biblioteca Android reutilizável para desenhar e exportar assinaturas; `:app` é demonstração técnica. A arquitetura existente está descrita em [`ARCHITECTURE.md`](../ARCHITECTURE.md).

Crie um plano quando a solicitação envolver funcionalidade relevante, alteração arquitetural, migração, refatoração ampla, múltiplos módulos ou risco significativo. Para mudanças pequenas e isoladas, registre o necessário na documentação técnica e no changelog sem criar plano artificial.

Use [`TEMPLATE.md`](./TEMPLATE.md) para iniciar planos novos. Requisitos de produto, prioridades, responsáveis e roadmap não estão definidos nesta documentação e devem ser confirmados antes de tratá-los como decisões.
